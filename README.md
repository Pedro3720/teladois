# TelaDois

Transforma o iPhone em **segunda tela do PC (via cabo USB)** e em um **Modo Descanso** estilo StandBy — relógio, clima, bateria e Spotify — sem precisar do carregador.

- Especificação: [docs/superpowers/specs/2026-10-16-iphone-segunda-tela-descanso-design.md](docs/superpowers/specs/2026-10-16-iphone-segunda-tela-descanso-design.md)
- Como instalar no iPhone: [docs/INSTALACAO.md](docs/INSTALACAO.md)
- **Instalar no PC (Windows):** baixe o `TelaDois-Setup-….exe` da [página de versões](https://github.com/Pedro3720/teladois/releases) e abra — ele instala o app, o FFmpeg e o monitor virtual de uma vez. Detalhes em [docs/INSTALACAO.md](docs/INSTALACAO.md#no-pc-windows).

O app iOS é compilado pelo GitHub Actions (macOS) sem assinatura e instalado pelo xtool (ou Sideloadly) com um Apple ID grátis.
